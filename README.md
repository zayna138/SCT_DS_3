# SCT_DS_3 - Decision Tree Classifier

This project uses a Decision Tree Classifier to predict passenger survival on the Titanic dataset.

## Objective

Build a machine learning classification model using Python and Scikit-learn.

## Dataset

Titanic Dataset

## Libraries Used

- Pandas
- Matplotlib
- Scikit-learn

## Features Used

- Passenger Class
- Sex
- Age

## Steps Performed

1. Loaded the Titanic dataset
2. Cleaned missing values
3. Converted categorical data into numeric format
4. Selected important features
5. Split data into training and testing sets
6. Trained a Decision Tree Classifier
7. Evaluated model accuracy
8. Visualized the Decision Tree

## Model Accuracy

The model predicts passenger survival with good accuracy.

## Output

- Decision Tree visualization
- Accuracy score
